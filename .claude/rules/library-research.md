# Library Research Rules

When working with external libraries, packages, or APIs:

1. **Always use WebSearch first** - Verify current documentation before writing code
2. **Search for latest version** - Check "[library] latest version [year]"
3. **Confirm API usage** - Methods may have changed
4. **Include source links** - Link to documentation in responses
